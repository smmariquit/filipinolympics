# FWDPeers - FilipinOlympics

A mobile minigame with a Filipino twist, made in Godot for Game Jam Los Baños 2025.

Play or download the build on itch.io: https://jlscsr.itch.io/fwdpeers-filipinolympics

## Credits

Code and design by Jlscsr, Stimmie (Simonee Mariquit) and Julius Raagas.
